# Chii Arcade DEV Games

## Deutsch

Dieses Repository enthält experimentelle Android-DEV-Versionen für Chii Arcade 2.0. Sie sind keine stabilen Releases und können Fehler enthalten oder sich ändern.

**Chii Cloud DEV ist derzeit nur für freigegebene Tester zugänglich und nicht allgemein öffentlich verfügbar.** DEV-Spiele werden parallel zu ihren normalen Apps installiert und können eigene lokale Testspielstände führen. DEV-Spielstände sind getrennt und möglicherweise nicht mit stabilen Versionen kompatibel.

Für die normale Chii Arcade besuche den [Store](https://chobitschii.github.io/chii-arcade/). Die offiziellen stabilen Spiele-Releases bleiben an ihren bisherigen Orten im [Spiele-Release-Repository](https://github.com/ChobitsChii/games/releases); dieses Repository ersetzt oder verändert sie nicht.

APK-Metadaten und Prüfsummen werden vor Veröffentlichung geprüft. Chii Arcade vertraut einem DEV-Signaturzertifikat nur, wenn es unabhängig geprüft und in der DEV-App lokal gepinnt wurde. Katalogdaten können diesen Pin nicht ändern.

## English

This repository contains experimental Android DEV builds for Chii Arcade 2.0. They are not stable releases and may change or contain bugs.

**Chii Cloud DEV is currently available only to approved testers and is not generally public.** DEV games install alongside their normal apps and can keep separate local test saves. DEV saves are separate and may not be compatible with stable versions.

For the regular Chii Arcade experience, visit the [store](https://chobitschii.github.io/chii-arcade/). Official stable game releases remain in their existing locations in the [game releases repository](https://github.com/ChobitsChii/games/releases); this repository does not replace or modify them.

APK metadata and checksums are verified before release. Chii Arcade trusts a DEV signing certificate only after independent verification and a local pin in the DEV app. Catalog data cannot change that pin.
