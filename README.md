# Chii Arcade DEV Games

This repository hosts experimental Android DEV builds for Chii Arcade 2.0. These builds are for testing and feedback; they are not stable releases and may change, contain bugs, or use test data.

Chii Cloud DEV is currently restricted to approved testers and is not generally available to the public. A DEV game may be installed alongside its normal app and may keep separate local test saves. Do not expect DEV saves to transfer to, or remain compatible with, stable releases.

For the normal Chii Arcade experience, visit [Chii Arcade](https://chobitschii.github.io/chii-arcade/). Official stable game releases are linked from the store and remain in their existing release locations. This repository does not replace or modify those releases.

Only APKs that have passed package, version, SHA-256, and signing-certificate checks should be attached to a release. The certificate fingerprint published in catalog metadata is informational; Chii Arcade verifies against its locally pinned DEV certificate and never trusts a remote catalog to change that pin.
